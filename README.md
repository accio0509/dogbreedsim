# 狗狗育种模拟器 V1.0.2

正式单机版，离线运行，无账号及联网服务。

## 启动
Windows：安装 Python 3 后双击「启动游戏.bat」，浏览器访问 http://127.0.0.1:5500/index.html。需确保5500端口未被其他程序占用。关闭服务窗口停止游戏服务器。也可使用 VS Code Live Server，或在本目录执行 `python -m http.server 5500 --bind 127.0.0.1`。

## 存档
使用原来的浏览器及原来的地址、端口打开游戏才能直接读取旧存档。不同地址/端口/浏览器配置的本地存储互相独立。升级前在游戏设置导出 JSON；需要迁移时在新版本导入。兼容 RC1 及已支持的旧版存档。导入前备份旧存档，损坏存档不会自动覆盖。不要清除站点数据。正式与开发模式存档独立。

## 玩法
选择初始犬，成长后可繁育；探索获得奖励，训练提高努力值，比赛按冠军逐级解锁。市场购买或租借配种，经营页面扩建设施及购买道具，仓库使用道具。图鉴记录各犬种基因，家谱记录亲缘关系。设置可调整游戏倍速。

## 正式版内容
24犬种、41等位基因、23道具、五张地图、七类比赛、女巫小屋、犬只退役、完整可交互家谱、独立图鉴及存档管理。包含最后一次RC1界面优化。本次仅正式化版本号及迁移兼容，不调整数值。

## 验证
开发者可运行 `node --experimental-default-type=module tests/run-v100.mjs`，以及 tests 下 balance-test、family-items-test、witch-routing-test、database-test、rc1-test、rc1-ui-test、final-release-test（均为 .mjs）。本地浏览器和 Windows 启动脚本仍需实际环境验证。
