# V0.4.0 开发者工具补丁

在 V0.4.0 正式接入补丁之上覆盖解压。正常打开 index.html，进入游戏设置 → 打开独立开发模式，或直接打开 index.html?dev=1（使用同一 Live Server 地址和端口）。首次可点「复制正式存档」，也可点击犬舍总览创建独立测试犬舍。

正式存档：`dogbreedsim:save`；测试存档：`dogbreedsim:save:dev`。开发模式仅写后者，复制、导入、重置前有覆盖确认。导入仅支持当前游戏可迁移的 JSON 存档，不提供反向覆盖正式存档。若要测试其他存档，请先导出当前测试存档。

快进：+1/12/24/48小时、+7天，同步推进自然成长、犬蛋孵化和冷却；人为快进分段跨越48小时离线上限。通过结算成长、调整计时起点实现，不改变电脑系统时间、事件历史时间或后代基因。未来探索、比赛等任务计时尚未接入。立即成年只作用于空闲未退役犬只（包括盒子、等待安置）。立即孵化只使犬蛋可领取。恢复繁育次数同时解除冷却，以符合原有引擎约束。生成测试犬遵循设施容量，产生一对成年犬及独立家谱。

经验显示：犬只列表及详情向下取整，内部仍保留小数，成长阈值和规则不变。

验收：Live Server 打开 tests/dev-test.html，运行测试（当前4犬种 ×14项，共56项）。原 tests/formal-test.html 仍预期264项通过。打开正式页面创建犬舍，进入独立开发模式复制，快进48小时再24小时，繁育并快进24小时，领取幼犬。返回正式游戏检查原存档未被修改。
