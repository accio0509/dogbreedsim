# V0.8.0 比赛、性格效果与操作优化

## 更新
将更新补丁解压到 V0.7.0 项目根目录，覆盖同名文件。不包含 .git。完整源码可独立运行。旧版存档自动迁移，建议备份正式存档后先在独立开发模式验收。无需新建犬舍。

## 成长与时间
- 自然成长基础 30 EXP/游戏小时；240 青年、720 成年，普通幼犬 8 小时青年、24 小时成年。
- 设置提供 1/2/3/5/10 倍速，默认 1。离线时间亦按保存的倍率推进。切换倍率先结算旧倍率，再以当前游戏时刻为新锚点；市场日期仍基于现实时间。开发者快进仍独立推进测试市场日期。
- 探索经验继续采用自然成长基础值×地图倍率；经验上限720，离线单次最多48游戏小时。升级前尚未结算的成长间隔会按新规则结算。
- 游戏内任务剩余时长用游戏时间显示；训练、探索、比赛界面定期刷新，可能有最多约30秒的显示延迟。真实计时与领取资格由引擎校验。

## 性格
温顺自然成长×1.2（从数据库原先1.1调整）；冒险探索×1.2；幸运道具及遇见幼犬概率×1.2且封顶100%；好胜比赛奖金×1.1；勤奋EV、贪吃零食、贪玩玩具仍×1.2。六项能力性格修正不变。

## 犬只选择
探索、训练（含道具）、繁育和比赛统一显示名称、性别、犬种、年龄阶段；租借犬额外标注。支持名称搜索（点击搜索）、性别、犬种、年龄、性格组合筛选；繁育父母本分开按固定性别筛选。编号仍用于内部主键和家谱。若多只犬四项显示信息完全相同，可通过性格筛选、犬只详情入口区分。
详情页可以移动至饲育屋/电脑盒子，或前往探索/训练/繁育/比赛并预选当前犬只，再选择项目并确认；不会自动改变位置或绕过资格检查。

## 比赛与荣誉
- 七类：竞速、障碍、服从、搜寻、耐力、力量、综合。幼犬、青年犬、成年犬自动分组；初级、中级、高级可直接选择。
- 仅空闲未退役的饲育屋自有犬可参加；免费报名、4游戏小时、同犬仅一场，不自然成长。多犬可并行。
- 三属性项目按50%/30%/20%加权，综合赛六维等权；加少量随机分，与5个同龄模拟对手比较。对手成年基准分范围60–100/85–125/110–150，按年龄系数缩放。并列分数时玩家优先。
- 初级第1至6名奖金180/120/80/40/20/10 G；中级×1.5、高级×2，好胜再×1.1，取整。比赛开始锁定成绩和奖金，完成手动领取；不自动重复，记录保留。犬只详情可查看该犬荣誉。
- 项目权重、难度、奖金、时长均为暂定平衡参数；无等级解锁、联网对手或赛事赛季。
