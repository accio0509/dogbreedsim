# V0.5.0 租借配种补丁
覆盖 V0.5.0 项目同名文件，不删除旧存档。市场新增租借配种选项卡，与购买库存独立，每日零点刷新六只成年犬。公母随机；相同属性下公犬为母犬半价（母犬基础价向上取偶数）。租借费用一次性支付，占用繁育室，成功产蛋后自动移除现役犬并保留家谱。自有亲本仍执行原繁育冷却和终生次数规则；不允许两个租借亲本互配。未配种的租借犬跨日保留，暂不提供提前归还或退款。现有存档自动添加租借库存。

测试：在项目根目录用 Node 执行 `node --experimental-default-type=module tests/run-v050.mjs` 和 `node --experimental-default-type=module tests/rental-test.mjs`。浏览器使用 Live Server 打开 index.html?dev=1，复制正式存档，增加资金及生成成年测试犬，在市场租借、进入繁育中心配种、孵化领取，检查余额、位置及家谱。若找不到体型兼容亲本，生成同犬种异性测试犬。不要直接使用正式存档测试。
