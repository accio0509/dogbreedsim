# V0.10.0 平衡、道具及扩展家谱补丁

安装：备份正式和测试存档，将补丁解压到原项目根目录覆盖同名文件。基线为已通过验收的 v100-database-full-source。版本号保持 0.10.0，旧存档兼容，不需清档。

## 平衡参数
- 时间与全局倍速不变；新比赛 1 小时；新训练 2 小时，旧训练任务保持原时长。
- 比赛奖金约为原来的四分之一（初级冠军45、中级67、高级90 G），高级赛任何名次赠一枚随机犬蛋，孵化24小时，无已知亲缘关系。孵化室满员保留待领奖状态；腾出空位后领奖。比赛时锁定犬蛋数据，旧任务可能在领奖时补生成奖励。
- 六种专项赛成年对手评分65–95/80–110/95–125，综合赛65–95/80–105/90–115。其他年龄按阶段折算，逐级冠军解锁不变。
- 设施逐级费用翻倍，全部扩建费用53400 G；不追溯已完成的升级。
- 两个市场仍各6只，付费刷新100 G，零点免费刷新。
- 空闲自有犬可以永久退役，释放容量，保留家谱、基因、属性和荣誉，不返还金钱，不可撤销。

## 道具
全部可在犬舍经营购买，在训练与道具页使用。只对空闲饲育屋自有犬使用；不适用、无库存或保存失败时不消耗。

| 道具 | 价格 G | 效果 |
|---|---:|---|
| 狗狗饼干 | 30 | 40 EXP，贪吃+20% |
| 耐咬玩具 | 45 | 60 EXP，贪玩+20% |
| 能量零食 | 75 | 100 EXP，贪吃+20% |
| 努力值重置卡 | 300 | 全部EV清零 |
| 训练营养剂 | 120 | 所选属性+20 EV，受单项100/总300上限限制 |
| 单项努力值重置卡 | 100 | 所选属性EV清零 |
| 平和性格卡 | 250 | 性格改为平和，基因与IV不变 |
| 繁育恢复剂 | 180 | 当前冷却最多缩短6小时，保留实际配种时间与次数 |

属性类道具使用上方选中的训练项目对应属性。冷却完成或繁育次数用尽不能使用恢复剂。恢复剂的减免仅作用于当前冷却，新配种重新计算。开发者工具可增加所有8种道具。

## 家谱
四代版仅包含所选犬上下各四代直系，不显示旁系；完整版遍历已记录亲子与配种关系构成的连通分量，包含多代父母、后代、兄弟姐妹、半同胞、配偶及其关联家谱。尚在孵化的配种也列入配种记录。父母在正常无循环档案中位于子女上方。实线表示亲子，虚线表示配种；点击任意犬节点重新以其为中心绘图。相同犬只只绘一个节点；复杂回交或多配偶可能产生交叉线，可滚动查看。编号仅用于内部识别，不显示给玩家。退役犬可查看只读档案。未知、未登记的亲属不能补出。
