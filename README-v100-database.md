# V0.10.0 犬种数据库补丁
覆盖至已安装 V0.10.0 的项目根目录。先导出并备份正式及开发存档。
- 来源：项目《整理游戏设定》中的24犬种基因池、41基因、显性等级及色值；六维沿用用户确认的恢复表。
- 旧编号按语义迁移，不按数字后缀迁移；旧有不符合新基因池的普通基因保留在原犬身上，后代按新母系基因池修正。表现型可能因显性等级和色值更新改变。旧租借商品保持挂牌价直至刷新。
- 新突变候选为该母系犬种常规池之外的全部颜色；突变来源标记可跨犬种保留。P/L不突变。
- 新犬种体重范围为暂定游戏参数，新增20种犬种定价分类暂为普通；原四种保持原定价分类及体重范围。无额外稀有犬种抽取权重。
- 图鉴独立计算并标注普通、稀有、突变途径；犬只基因表显示显性等级。
- 执行 `node --experimental-default-type=module tests/run-v100.mjs`（2085项回归检查），再执行 `node --experimental-default-type=module tests/database-test.mjs`（7200次生成、7200次连续遗传及突变和迁移校验）。
- 未做真实浏览器点击验收，未做长期经营经济平衡。旧版独立实验HTML中硬编码的旧基因编号不属于本次回归范围。
