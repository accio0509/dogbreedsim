# V0.10.0 — 比赛解锁、荣誉、树形家谱、分犬种图鉴
从 V0.9.0 更新。解压覆盖项目根目录，Ctrl+F5 刷新。先备份存档及提交 v0.9.0 Git 标签。

- 比赛按犬只、项目、年龄组分别解锁，初级免费开放，领取初级冠军后解锁中级，初中级均取得冠军才解锁高级。旧赛果永久保留；已开始的旧比赛允许领取。每场仍为一游戏小时。
- 犬只详情显示按年龄组、项目、等级汇总的冠军次数，非冠军仍在参赛记录内。数据从历史记录实时派生，无需新存档字段。
- 家谱采用带连线的父母树形分支，可横向滚动；四代祖先及直接后代，保留跨犬种及租借祖先。近交计算不变。
- 图鉴各犬种独立页面、独立基因与表现型统计，分母依据该犬种基因池及突变色，并包含历史记录中已获得的跨犬种突变等位基因。沿用永久档案（含租借犬），未领取犬蛋不计。
- 原有0.9及以前存档兼容。无新的平衡参数；24犬种最终原始数据未取回，因此仍有4个测试犬种，完整内容补全和数值平衡未完成。实际浏览器点击尚未验证。

测试：Live Server 打开 tests/v100-test.html 或终端运行 `node --experimental-default-type=module tests/run-v100.mjs`。预期485项通过（470项回归 + 15项新增）。涉及版本和比赛解锁的旧断言按新规则调整。
