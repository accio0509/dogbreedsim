# V0.9.0 犬舍经营与收集

覆盖 V0.8.0 项目文件即可。首次载入自动迁移 0.8.0 及此前受支持版本。建议先备份正式存档、提交 Git。

- 近交：实际家谱的祖先编号决定亲缘，犬种不影响 F；原引擎已支持，增加跨犬种实际产蛋回归测试及 UI 提示。原体型及繁育资格规则不变。
- 比赛：新比赛 1 游戏小时，旧四小时任务保持原时间及赛果。按进度显示等待、热身转圈、项目动作、阶段得分及暂时名次、裁判确认、最终成绩。得分及模拟对手在报名时锁定；阶段分按进度比例计算，旧任务无对手明细则显示等待阶段评分。界面定期刷新约30秒，焦点在筛选输入时暂缓。
- 犬舍经营：饲育屋 10→30（+5/500G），电脑 60→180（+20/300G），繁育 1→5（+1/800G），孵化 1→5（+1/1000G）。道具店购买现有三种成长道具，单价30/45/75G；购买与升级使用原存档事务回滚机制。
- 性状图鉴：永久档案中出现过的犬种、等位基因和实际显性性状。当前仅4犬种；图鉴统计包含登记的租借犬，不计尚未领取的犬蛋。
- 家谱：选择一只登记犬，查看四代祖先树和直接后代；近交计算仍使用完整家谱，不受显示深度限制。
- 繁育预测：各位点新突变前的显性等位基因概率，包含母系基因池修正；单独显示新突变基础概率。不是联合外貌或突变后精确概率，花纹显示还受毛色遮蔽影响。

测试：Live Server 打开 tests/v090-test.html，或运行 `node --experimental-default-type=module tests/run-v090.mjs`。预期470项通过。当前环境 Chromium 本地地址导航被管理员策略拦截，实际浏览器操作待本地验收。
