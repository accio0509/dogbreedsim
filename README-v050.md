# V0.5.0 犬只市场与购买系统

## 安装

1. 先提交或备份本地 V0.4.0 项目，以及浏览器存档（开发者工具可复制正式存档后导出 JSON）。不要清除站点数据。
2. 覆盖补丁解压到 dogbreedsim 根目录；完整源码包也可以解压到新的目录独立使用。不包含 .git，不会覆盖 Git 历史。完整包含之前上传源码及最终接入、开发者工具、领取修复补丁。
3. 使用 VS Code Live Server 打开 index.html，保持原浏览器、主机名及端口以读取原正式存档。Ctrl+F5 强制刷新。存档版本在下次成功保存后升级至 0.5.0，回退旧程序前请备份旧存档。
4. 开发模式进入 游戏设置 → 打开独立开发模式，复制正式存档（将覆盖现有测试存档）或建立新测试犬舍。

## 玩法及暂定平衡参数

- 每天浏览器本地日期零点刷新六只犬。未打开市场时不执行后台任务，下次进入按当前日期生成；当天不补货、不重抽。关闭或刷新后保留库存、价格与已售记录。
- 现有四个犬种等概率抽取，新增有合法基因池的犬种自动加入。年龄概率：幼犬 60%、青年 30%、成年 10%。性别由原引擎等概率生成。
- 市场来源沿用原遗传规则：每个具备普通和稀有两类的颜色等位基因按 80%/20% 抽取，绝不引入突变基因。该比例不是犬只出现稀有表现型的概率。
- 定价 = 犬种基础价（常见120、稀有220）+ 年龄加价（0/60/140）+ 个体值总和×3 + 每个可见稀有颜色×35。隐藏花纹不加价。参数集中在 config/market.js。
- 预览只读，不允许改名、移动或繁育。确认购买才扣款，采用正式顺序编号，商品属性不重抽。购买时间起计算成长，犬只登记为初代并添加永久家谱及事件。优先饲育屋，其次电脑盒子，两者都满时拒绝购买；不进入等待安置。资金不足或保存失败不扣款、不分配编号。
- 暂不加入玩家出售/退役回收、货币收入新渠道。价格、年龄分布、犬种抽取权重及满员拒购规则是本次实现的可调整决定。初始资金1000不变。

## 开发工具

- 原有快进会推进市场日期，市场推进一天按钮等效于快进24小时（也推进成长、孵化及冷却）。可重复跨日，但同日不能反复随机。
- 增加1000测试金钱只作用于独立开发存档。正式存档键保持不变。

## 验收

打开 tests/market-test.html 并点击运行全部自动测试：预期 352 通过、0 失败（现有四犬种）。Node 22 可运行 `node tests/run-v050.mjs`。本包实际运行结果：市场32/32，原有功能回归320/320；JS语法检查通过。当前执行环境浏览器访问本地站点被管理策略拦截，真实点击尚待本地验收。

本地开发模式：进入市场查看6只，打开只读详情，取消确认不扣款；确认购买后检查余额、饲育屋或电脑盒子、家谱、事件；刷新后已售商品不可重复购买；快进24小时后刷新六只；增加测试资金并确认正式余额/库存不变。若使用正式存档测试，购买会真实消耗该存档资金。完成后回归繁育、领取、成长，确认旧数据仍在。

验收后再提交 Git；不要在未验收时添加 v0.5.0 标签。
