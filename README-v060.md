# V0.6.0 地图与探索系统
在已经通过 V0.5.0（含租借配种）的项目上覆盖补丁；同一浏览器、同一 Live Server 地址继续使用旧存档，自动迁移 0.5.0 至 0.6.0。建议先 Git 提交并标记 v0.5.0，再覆盖。完整源码包不含 .git。

五张地图常驻开放，每图同时一只空闲自有饲育屋犬，不限制年龄。探索仍占用饲育屋容量，不能移动或配种。独立成长经验按地图倍率结算，单次离线上限48小时，成年封顶720；不叠加普通成长。任务按固定时长完成后等待手动领取，等待时不再增长；提前返回保留已获经验但没有奖励。任务启动时锁定随机奖励，避免刷新重抽。金钱必得、道具及幼犬随机。幼犬为无已知亲缘关系的初代，普通/稀有颜色权重80/20，不含突变；可领养或拒绝，设施满可等待腾出空间或只领取金钱道具。领取成功后犬只返回空闲，恢复普通成长。奖励与任务一次性持久化。

地图数值集中在 config/exploration.js，均为暂定；已有任务保存时长和奖励，修改地图参数前请先完成旧任务（校验会检查配置一致性）。道具仓库仅收集，暂未提供使用功能。开发模式快进同步推进探索，新增「当前任务必遇幼犬」用于测试领养，正式存档不受影响。
